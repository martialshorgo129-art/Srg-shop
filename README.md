## Design Choices and Development Process

### 1. Design Concept and Inspiration

The idea behind SRG SHOP was to create a modern and attractive online store dedicated to African Wax and Chiganvy fabrics. I wanted the website to reflect the beauty, colors, and cultural richness of African textiles while maintaining a clean and professional appearance.

### 2. Color Palette and Visual Identity

I chose a colorful visual style inspired by the vibrant patterns of African fabrics. The design combines these cultural influences with a clean layout to create a balance between tradition and modernity. The SRG SHOP brand name is clearly displayed to make the store recognizable.

### 3. Layout and Content Organization

I organized the page into several sections to make navigation simple and intuitive. The navigation bar helps users move around the website, while the hero section introduces the store and encourages visitors to explore the collection. Product cards display fabric images, descriptions, and prices, making it easier for customers to discover the available products.

### 4. Typography and Readability

I selected clear and readable typography to ensure that visitors can easily understand the content. Titles are used to highlight important information, while descriptions provide additional details without making the page look crowded.

### 5. Responsive Design and User Experience

Since customers may visit the website using different devices, I used Bootstrap and CSS media queries to make the layout responsive. The goal was to ensure that the website remains attractive, readable, and easy to navigate on desktop, tablet, and mobile screens.

### 6. From Initial Idea to Final Result

I started by identifying the purpose of the store and the type of customers it could attract. I then planned the main sections, chose a visual style inspired by African fabrics, and organized the content to create a smooth browsing experience. After building the page with HTML, styling it with CSS, and using Bootstrap for responsive components, I reviewed the layout and adjusted the spacing, alignment, and section presentation.

The final result is SRG SHOP, a responsive landing page that combines African textile inspiration with a modern e-commerce layout. It presents the fabric collection clearly while providing a consistent visual identity and a user-friendly experience.
